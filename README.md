# Credal — pilots

1 working pilot built for Credal.

### Permission leak harness

A support rep asks what the severance package is and the assistant answers correctly, from an HR document she cannot open. Across four users and eight questions, 31% of answers come from a document the asker had no access to — and every one of them reads like a good answer.

`companies/credal/credal-permission-leak/`

## Running it

```bash
npm install
npm run dev
```

## Note on the data

Every figure in these pilots is synthetic and labelled as such in the interface.
Nothing here is connected to Credal's systems, and no number should be
read as a measurement of their business.
